# 📊 Data

This folder contains the **raw and cleaned datasets** used for the Q3 Marketing Performance Analysis.

## Data Contents

The datasets include information used to analyse:

- Marketing campaigns
- Advertising spend
- Impressions and clicks
- Leads and conversions
- Revenue
- ROI
- Marketing channels
- Regions
- Campaign status

## Data Preparation

The raw dataset was reviewed and prepared for analysis by:

- Removing duplicate records
- Handling missing values
- Standardizing inconsistent formats
- Recalculating missing ROI values
- Validating the data for analysis

The cleaned dataset was then used for KPI analysis, dashboard development, business insights, and Q4 revenue forecasting.
